# AI 작업 기록

이 디렉터리는 중요한 설계 선택과 다단계 작업의 실행 기록을 남긴다. 공통 안전 규칙과 작업 라우팅의 권위는 항상 `AGENTS.md`와 `.agents/*`에 있다. 이곳은 이를 복제하거나 완화하지 않는다.

## 언제 기록하는가

- public API/event, schema/RLS/보존, 인증·비밀·개인정보, 트랜잭션·재시도·순서, 서비스 경계, 주요 의존성 또는 아키텍처를 결정할 때는 `designs/` 또는 `decisions/`를 사용한다.
- 여러 단계·모듈에 걸친 실행은 `plans/active/`에서 시작하고, 완료 후 결과를 채워 `plans/completed/`로 옮긴다.
- 작은 가역 수정, 문구·스타일 변경, 명확한 단일 파일 수정에는 이 기록이 필요 없다.

## 역할 분리

| 위치 | 책임 |
| --- | --- |
| `AGENTS.md`, `.agents/*` | 규칙, 안전, 작업 라우팅 |
| `docs/ai/` | 설계·결정·실행 계획과 결과 |
| `wiki/` | 탐색, 출처 연결, 재사용 가능한 학습·회고 |

위키에는 이 문서의 원문을 복제하지 않는다. 필요하면 문서 링크와 출처, 재사용 가능한 요약만 남긴다. 실제 코드·설정 및 `AGENTS.md`·`.agents/*`와 위키가 다르면 전자가 우선한다.

## 사용 순서

1. 관련 규칙과 기존 구현, 필요하면 위키를 탐색한다.
2. 중요한 선택이면 설계 또는 결정 기록을 남긴다.
3. 다단계 실행이면 활성 계획을 만들고 검증·롤백 조건을 적는다.
4. 완료 시 실제 결과와 검증, 편차를 채운 뒤 완료 계획으로 옮긴다.

템플릿은 최소 기록을 돕기 위한 것이다. 작업에 맞지 않는 빈 항목은 삭제하거나 `해당 없음`으로 표시한다.

## 모델과 추론 effort

모델의 역량·가격과 추론 effort는 같은 등급이 아니다. 최상위 모델도 하네스가 지원하면 `low` effort로 시작할 수 있다. 필요한 품질을 얻지 못했거나 불확실성·실패 비용이 높을 때만 `medium` 이상으로 올린다.

모델 선택 전에는 각 하네스에서 실제 선택 가능한 모델·effort·사용량 한도를 확인한다. 구독 사용량은 API 토큰 가격과 일대일로 대응하지 않으므로, 가격표만으로 특정 모델이나 effort를 강제하지 않는다.
