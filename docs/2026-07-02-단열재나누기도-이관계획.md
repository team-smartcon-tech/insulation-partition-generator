# 단열재 나누기도 — SSX → 독립 프로젝트 이관 계획

> 작성: 2026-07-02
> 최종 수정: 2026-07-02
> 상태: 진행중 (뼈대 생성 완료 → 기능 이식 예정)

SSX(`smart-schedule-X`)의 본사 메뉴 **"단열재 나누기도"** 기능을 **동작 그대로** 별도 저장소로 떼어내고,
**새 Cloudflare Worker + 새 Supabase 프로젝트**로 이관한다. 원본 SSX 저장소는 **읽기 전용 참조**이며 수정하지 않는다.

---

## 1. 이 기능이 하는 일

DXF 도면을 올려 외벽을 따라 그리면, 외단열재(외단열, 보통 2겹 예: 70+70)를 어떻게 조각내 붙일지
**"나누기도"** 를 자동으로 그려주고, **주문 자재 수량**까지 산출한다.

- 입력: 사용자가 올리는 **DXF 도면** + 화면에서 **외벽 라인 직접 그리기** + 창/문(개구부)·보드 규격·정책 설정
- 출력: 화면 미리보기(canvas), **DXF/SVG(도면)**, **CSV/XLSX(수량표)**, **ZIP(묶음)** — 전부 브라우저에서 생성·다운로드
- 핵심 계산: 외벽 펼치기, 모서리 겹침(코너 랩) 처리, 창/문 구멍 빼기, 남는 조각 재활용(2D 빈패킹), 수량 산출, 결로 방지 이음매 간격 검사

원본 상세 명세: SSX `docs/2026-06-26-단열재나누기도_물량산출_개발요구명세서.md`

## 3. SSX와의 결합부 → 새 프로젝트에서 교체/재구성

| 결합부 | 원본에서 하던 일 | 이관 조치 |
| --- | --- | --- |
| `HQLayout` / `HQSidebar` | 본사 화면 껍데기 | 단독 앱의 단순 레이아웃으로 교체 |
| `menuRegistry` / `RouteAccessGate` / `useMenuAccess` | 본사 RBAC 메뉴 `hq-elevation-gen` | 제거 (단독 앱은 자체 라우팅) |
| DCR 인증(`getDcrToken` 등) | SSX 로그인 토큰 | 새 앱 인증으로 교체 (방식 미정) |
| `@/components/ui/button` + `cn` | shadcn 버튼/클래스 유틸 | 소형이라 그대로 이식 |
| 저장 API(worker) + 공용 `schedule-private` 버킷 | 15k줄 SSX worker 안 | 새 프로젝트 전용 작은 worker + 새 Supabase 테이블 2개 + 전용 버킷 |

`ThemeContext`, 공용 `types`/`shared`는 이 기능이 **사용하지 않음** → 조치 불필요.

---

## 4. 이관 단계 계획

- **1단계 (완료): 프로젝트 뼈대** — 모노레포(apps/web·apps/worker·packages/shared) + 규칙 문서 + 최소 설정 + git 저장소. 화면·기능 코드 없음.
- **2단계: 생성 기능 이식** — 핵심 코드(위 2절 상단)를 apps/web로 옮기고 HQ 껍데기·메뉴 결합부 제거. 로컬에서 DXF 업로드→나누기도→내보내기가 **서버 없이** 동작하게. (Tailwind+shadcn button, dxf-parser/xlsx/jszip 등 설치)
- **3단계: 저장/불러오기 이식** — apps/worker에 저장 API 재구성 + 새 Supabase 프로젝트에 테이블 2개 + Storage 버킷 생성 + 인증 방식 확정. `packages/shared`에 `ElevState` 등 공용 타입 이식.
- **4단계: 배포** — 새 Cloudflare Worker 배포 + 새 Supabase 연결. (사용자 승인 후)

각 단계는 만들기 전에 계획을 보여주고 승인받아 진행한다.

---

## 5. 스택 결정 (요약)

- 프론트: **Vite + React + wouter** (표준 React Router v7 대신 — 원본 동작 그대로 이관. `.agents/STACK.md` Project Override 참조)
- 서버: **Hono / Cloudflare Worker** (표준 유지)
- DB/Storage: **Supabase** (신규 프로젝트, 표준 유지)
- UI: **Tailwind + shadcn/ui** (원본 동일)
- 상태/데이터: TanStack Query(저장/불러오기), Zod(검증)

---

## 6. 안전 원칙

- 원본 SSX 저장소는 읽기 전용. 수정 금지.
- 비밀값(Supabase 키/JWT)은 코드·문서·`.env` 커밋 금지 → Cloudflare Secrets 관리. 프론트엔드에 서버 비밀값 노출 금지.
- 비공개 Storage 파일은 서명 URL(signed URL)로만 임시 발급. 인증 없이 URL 직접 발급 금지.
- 커밋/푸시/배포/운영 DB 변경/삭제성 마이그레이션은 사용자 승인 후에만.
