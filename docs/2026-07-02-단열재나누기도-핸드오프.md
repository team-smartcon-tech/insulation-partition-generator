## 3. 실행 방법

```bash
# 사전: Node 20+, pnpm 10.x (corepack 권장)
pnpm install                 # 저장소 루트에서 (워크스페이스 전체)
pnpm --filter web dev        # 개발 서버 → http://localhost:5173
#   ※ 5173이 다른 앱에 점유돼 있으면 Vite가 자동으로 5174 등 다음 포트를 사용(콘솔 URL 확인)
pnpm --filter web build      # 프로덕션 빌드(타입체크 포함)
pnpm --filter web typecheck  # 타입 검사만

# ── 저장/불러오기까지 로컬에서 확인 ──
pnpm --filter worker dev     # 로컬 Worker(8787). web dev의 /api 프록시 기본 타깃
#   (Supabase 실호출까지 보려면 apps/worker 에 .dev.vars 로 SUPABASE_URL/SERVICE_ROLE_KEY 제공)

# ── 배포(부트스트랩; 정식은 GitHub 연결 자동배포 권장) ──
#   unset CLOUDFLARE_API_TOKEN  # 셸에 무효 토큰 남아 있으면
#   cd apps/worker && pnpm --filter web build && npx wrangler deploy   # Smarttech 계정
```

화면에서: DXF 업로드 → 외벽 트레이싱 → 나누기도 미리보기 → 매트릭스/산출서 → 내보내기 + **프로젝트/REV 저장·불러오기**(라이브에 이관 데이터 2개 프로젝트 존재).

- 소스 SSX dev(`ssx_elev_*`) → 타깃 신규(`elev_*`): **프로젝트 2 / 리비전 5** 이관(id·rev_no·state·summary·created_at·created_by 보존).
- **DB만** 방침: `dxf_path`/`dxf_bucket`=null(원본 DXF 파일 미복사), `dxf_name`/`dxf_size` 메타는 유지. 불러오기 시 도면은 `state`로 복원되나 DXF 언더레이는 없음.

### 3-E. 인증 — DCR 통합로그인(회원) 추가 (코드 완료, 배포 시크릿 대기)
- **방식**: 앱 전체 로그인 벽. 신규 Worker가 배포 dcr-app의 `POST /api/auth/login`(**이메일+비밀번호, SSX 로그인과 동일**)을 서버-투-서버 호출 → 응답 `{ok,user}`만 신뢰(토큰 폐기) → **자체 시크릿 `IPG_JWT_SECRET`(HS256)** 으로 aud/iss=`insulation-partition-generator`, 12h 만료 세션 토큰 재발급 → HttpOnly 쿠키 `ipg_session`. **DCR의 JWT_SECRET 미공유**(유출돼도 DCR 본체엔 무효). 허용 role: super_admin/system_admin/site_admin/member.
- **파일**: worker `apps/worker/src/auth.ts` + `index.ts`(`/api/auth/{login,logout,me}` + `app.use('/api/*', authMiddleware)`, `created_by`=로그인 id). web `apps/web/src/features/auth/*`(AuthContext·AuthGate·LoginPage·authApi) + `main.tsx`·`App.tsx`(`/login`+게이트)·`elevation/api.ts`(credentials+401 이벤트).
- **환경 분리**: `DCR_BASE_URL` prod=`dcr-app.jogh.workers.dev`(wrangler.jsonc), dev/로컬=`dcr-app-dev.jogh.workers.dev`(`.dev.vars`). 로컬은 `COOKIE_SECURE=false` 필수.
- **로컬 개발**: `cp apps/worker/.dev.vars.example apps/worker/.dev.vars` 후 `pnpm dev`(worker+web 동시). 배포 dcr-app 회원계정으로 로그인.
- **검증**: typecheck/build/dry-run 통과, 로컬 게이트(미인증 401·/health 통과) + 로컬→배포 dcr-app member/login 연결(가짜계정 401) 확인. 코드리뷰로 stale-세션·role fail-open 버그 2건 수정.
- ⬜ **배포 전 필수(사용자)**: 운영 Worker에 **`IPG_JWT_SECRET` 시크릿 등록**(강한 랜덤값, `wrangler secret put IPG_JWT_SECRET`). 없으면 로그인 500.
- ⬜ **보안 후속(권장)**: 로그인 rate-limit용 **KV 네임스페이스 생성+바인딩**(`RATE_LIMIT`) — 현재 미바인딩이라 제한 미작동(프로덕션 회원 대상 브루트포스 방어 필요). Cloudflare WAF Rate Limiting Rule(`/api/auth/login`)도 대안.
