07 / 09
세 단계, 첫 세팅은 10–15분입니다
담당자는 폴더를 준비하고 결정에만 답합니다. 나머지 실행은 AI가 직접 진행합니다.
01
폴더 준비
저장소를 ZIP으로 받아 압축을 풀고, 폴더 이름을 내 프로젝트 이름으로 바꿉니다.
복제(clone) 대신 ZIP — 내 작업이 템플릿 저장소로 올라가는 사고를 막습니다
02
안전장치 켜기
명령 한 줄로 내 컴퓨터의 차단 장치를 켜고, GitHub 저장소에 main 보호 규칙을 한 번 걸어 둡니다.
이 단계를 건너뛰면 앞 장의 자동 차단이 전혀 작동하지 않습니다
03
AI에게 맡기기
Claude Code에 /onboard 한 줄. 환경 설정, 안전장치, 프로젝트 정보 입력, 화면 한 곳 수정, 첫 작업 기록까지 AI가 진행합니다.
Codex · Copilot은 준비된 시작 프롬프트를 붙여넣습니다
