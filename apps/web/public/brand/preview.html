마크가 담은 것 — 실제 작업 순서 그대로

① 점선 L자 = 평면 도면(입력, 아직 펼치기 전) → ② 주황 점선 호 = 펼침(전개) → ③ 격자 패널 = 전개된 외벽, 세로 조인트가 켜마다 엇갈림(실제 시공 방식) → ④ 주황 보드 2장 = 나누기 결과(색은 여기만) → ⑤ 창호 오프닝 = 보드가 이걸 피해 잘림 → ⑥ 아래 치수선 = 물량 산출까지.
